# Botón (Componente UI)

A diferencia del _shortcode_ `<Boton />` que vimos anteriormente (el cual se usa para formatear botones **dentro del contenido Markdown**), esta página sirve como un **ejemplo de cómo documentar componentes React o de UI** para tu propio desarrollo.

DOQMEN es perfecto para documentar librerías de componentes (por ejemplo, aquellos basados en _shadcn/ui_). Aquí te mostramos cómo podrías estructurar la documentación de tus propios componentes:

## Instalación del componente

Dado que estás desarrollando tu propio sistema, primero indicarías cómo agregar este componente a un proyecto.

```bash
npx shadcn@latest add button
```

## Importación

Luego, enseñarías la importación desde tu archivo local en React.

```tsx
import { Button } from "@/components/ui/button";

export default function Home() {
  return (
    <Button style={{ backgroundColor: "var(--color-accent)", color: "white" }}>
      Haz clic aquí
    </Button>
  );
}
```

## Resumen

- Usa **Shortcodes** (`<Boton />`) para darle vida e interactividad a la documentación de DOQMEN.
- Usa **Secciones de Componentes** (como esta página) para documentar el código, la API y el uso de los componentes en los proyectos de tu sistema de diseño.
