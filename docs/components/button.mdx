# Botón

Ejemplo de la documentación para un componente sin borde ni sombra de acuerdo con las especificaciones del diseño actual.

## Importación

Asegúrate de importar el componente local.

```tsx
import { Button } from "@/components/ui/button";

export default function Home() {
  return (
    <Button style={{ backgroundColor: "var(--color-accent)", color: "white" }}>
      Haz clic aquí
    </Button>
  );
}
```
