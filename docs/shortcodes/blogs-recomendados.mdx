## 1. Código del Shortcode

Copia este bloque HTML y pégalo en la pestaña **"Vista de HTML"** de tu editor en Blogger:

```html
<div class="mt-recommended">
    <a href="URL_DEL_BLOG" class="mt-blog-card" target="_blank">
        <div class="mt-blog-icon">
            <svg class="i i-file-lines" viewBox="0 0 24 24">
                <path d="M14 2H6a2 2 0 0 0-2 2v16a2 2 0 0 0 2 2h12a2 2 0 0 0 2-2V8Zm2 11H8m8 4H8m4-8H8"></path>
            </svg>
        </div>
        <div class="mt-blog-info">
            <span class="mt-blog-name">#NOMBRE_DEL_BLOG</span>
            <span class="mt-blog-desc">#DESCRIPCION_DEL_BLOG</span>
        </div>
    </a>

    <a href="URL_DEL_BLOG" class="mt-blog-card" target="_blank">
        <div class="mt-blog-icon">
            <svg class="i i-file-lines" viewBox="0 0 24 24">
                <path d="M14 2H6a2 2 0 0 0-2 2v16a2 2 0 0 0 2 2h12a2 2 0 0 0 2-2V8Zm2 11H8m8 4H8m4-8H8"></path>
            </svg>
        </div>
        <div class="mt-blog-info">
            <span class="mt-blog-name">#NOMBRE_DEL_BLOG</span>
            <span class="mt-blog-desc">#DESCRIPCION_DEL_BLOG</span>
        </div>
    </a>
</div>
```

---

## 2. Instrucciones de Personalización
Para cada tarjeta dentro del contenedor, debes actualizar los siguientes campos:

- **URL_DEL_BLOG:** Reemplaza este valor por la dirección web completa del sitio recomendado.
- **#NOMBRE_DEL_BLOG:** Escribe el título o nombre oficial del sitio.
- **#DESCRIPCION_DEL_BLOG:** Añade una breve frase que describa el contenido de ese blog.
