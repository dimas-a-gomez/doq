El shortcode de **Autor** genera una tarjeta informativa ideal para colocar al final de las entradas, permitiendo destacar quién escribió el contenido.

## 1. Código del Shortcode

Copia el siguiente bloque HTML y pégalo en la pestaña **"Vista de HTML"** de tu editor en Blogger:

```html
<div class="mt-author-card">
    <img src="#URL" alt="Autor" class="mt-author-avatar">
    <div class="mt-author-info">
        <span class="mt-author-name">#NOMBRE_DEL_AUTOR</span>
        <p class="mt-author-bio">
            #BIOGRAFIA_DEL_AUTOR
        </p>
        <div class="mt-author-social">
            <a href="#URL_SOCIAL"><svg>...</svg></a>
            <a href="#URL_SOCIAL"><svg>...</svg></a>
            <a href="#URL_SOCIAL"><svg>...</svg></a>
        </div>
    </div>
</div>
```

---

## 2. Instrucciones de Personalización
Para que tu perfil luzca profesional, actualiza los siguientes valores:

- **#URL (Imagen):** Reemplaza por el enlace directo de la foto de perfil del autor.
- **#NOMBRE_DEL_AUTOR:** Escribe el nombre completo o alias del redactor.
- **#BIOGRAFIA_DEL_AUTOR:** Una breve descripción profesional o personal sobre el autor.
- **#URL_SOCIAL:** El enlace a los perfiles sociales (Instagram, Twitter, etc.).
- `<svg>...</svg>` : Pega aquí el código SVG de los iconos (puedes obtenerlos de Meteor Icons).
