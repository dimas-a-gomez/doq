The **Author** shortcode generates an informative card, ideal for placing at the end of posts, allowing you to highlight who wrote the content.

## 1. Shortcode Code

Copy the following HTML block and paste it into the **"HTML View"** tab of your Blogger editor:

```html
<div class="mt-author-card">
    <img src="#URL" alt="Author" class="mt-author-avatar">
    <div class="mt-author-info">
        <span class="mt-author-name">#AUTHOR_NAME</span>
        <p class="mt-author-bio">
            #AUTHOR_BIO
        </p>
        <div class="mt-author-social">
            <a href="#SOCIAL_URL"><svg>...</svg></a>
            <a href="#SOCIAL_URL"><svg>...</svg></a>
            <a href="#SOCIAL_URL"><svg>...</svg></a>
        </div>
    </div>
</div>
````

---

## 2. Customization Instructions

To make your profile look professional, update the following values:

* **#URL (Image):** Replace with the direct link to the author's profile picture.
* **#AUTHOR_NAME:** Enter the full name or alias of the writer.
* **#AUTHOR_BIO:** A brief professional or personal description of the author.
* **#SOCIAL_URL:** Links to social media profiles (Instagram, Twitter, etc.).
* `<svg>...</svg>`: Paste the SVG code for the icons here (you can get them from Meteor Icons).
