El shortcode de **Resumen** genera un bloque destacado con un icono de estrella, diseñado para capturar los puntos más importantes de tu contenido.

## 1. Código del Shortcode

Copia este bloque HTML y úsalo en la **"Vista de HTML"** de tu editor en Blogger:

```html
<div class="mt-summary-box">
    <div class="mt-summary-title">
    <svg class="i i-star" viewBox="0 0 24 24">
    <path d="m12 1.5 3.1 6.3 6.9 1-5 4.8 1.2 6.9-6.2-3.2-6.2 3.2L7 13.6 2 8.8l6.9-1z"></path>
</svg> #RESUMEN
    </div>
    <p class="mt-summary-content">
    #DESCRIPCION_DEL_RESUMEN
    </p>
</div>
```

---

## 2. Instrucciones de Personalización
Para adaptar este bloque a tu artículo, reemplaza los siguientes valores:

- **#RESUMEN:** Es el título del bloque (ejemplo: **"Lo que aprenderás"**).
- **#DESCRIPCION_DEL_RESUMEN:** El texto detallado con los puntos clave o la síntesis de la entrada.
