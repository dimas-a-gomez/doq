El shortcode de **Bloque de Código** permite insertar fragmentos de programación de forma limpia, organizada y con una interfaz que simula un editor de texto moderno.

## 1. Código del Shortcode

Copia el siguiente bloque HTML y pégalo en la pestaña **"Vista de HTML"** de tu editor en Blogger:

```html
<div class="mt-code-wrapper">
    <div class="mt-code-header">
        <div class="mt-code-dots">
            <span class="dot-1"></span>
            <span class="dot-2"></span>
            <span class="dot-3"></span>
        </div>
        <span class="mt-code-lang">#LENGUAJE</span>
    </div>
    <pre class="mt-code-content" style="padding: 0; overflow: hidden;">
        <textarea readonly="readonly" style="width: 100%; background: transparent; border: none; color: inherit; font-family: inherit; font-size: inherit; resize: none; outline: none; padding: 20px; box-sizing: border-box; display: block;" oninput='this.style.height = "";this.style.height = this.scrollHeight + "px"'>
</textarea>
    </pre>
</div>
```

---

## 2. Instrucciones de Personalización
Para que el bloque se vea correctamente, realiza estos ajustes:

- **#LENGUAJE:** Reemplaza este valor por el nombre del lenguaje que estás mostrando (ejemplo: HTML, CSS, JavaScript, XML).
- **Contenido:** Pega el código que deseas mostrar dentro de las etiquetas `<textarea>` . Asegúrate de no borrar los atributos del textarea para mantener el auto-ajuste de altura y el diseño.
