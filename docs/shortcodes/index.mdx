---

Los **Shortcodes** en la plantilla **MountainB** son fragmentos de código HTML pre-diseñados que te permiten añadir funciones avanzadas y elementos visuales complejos a tus entradas de Blogger sin necesidad de escribir CSS o JavaScript adicional.

Están diseñados bajo una filosofía de **ligereza y estética moderna**, asegurando que tu blog cargue rápido mientras ofrece una experiencia de usuario de alta calidad.

---

## 🚀 Cómo usar un Shortcode

Para implementar cualquier elemento de esta lista en tu blog, sigue estos pasos:

1. **Copia el código**: Selecciona el bloque de código del componente que deseas usar desde esta documentación.
2. **Editor de Blogger**: Crea una nueva entrada o edita una existente.
3. **Vista HTML**: Cambia el modo de edición de "Vista de Redacción" a **"Vista en HTML"**.
4. **Pega y Personaliza**: Pega el código en la posición deseada y reemplaza los valores marcados con `#` (ej: `#URL`, `#TITULO`) por tu propio contenido.

* **[Bloque de Código](./bloque-de-codigo)**: Visualizador de fragmentos de programación.
* **[Botón de Descarga](./descargar)**: Botón estilizado para archivos.
