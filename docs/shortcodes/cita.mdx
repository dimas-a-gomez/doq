El shortcode de **Cita** permite destacar declaraciones de autores o frases célebres utilizando un icono decorativo y una tipografía diferenciada.

## 1. Código del Shortcode

Copia este bloque HTML y pégalo en la pestaña **"Vista de HTML"** de tu editor en Blogger:

```html
<blockquote class="mt-quote-free">
    <svg class="i i-quote-left" viewBox="0 0 24 24">
        <path d="M5 13h5v5H5v-7a4 5 0 0 1 4-5m5 7h5v5h-5v-7a4 5 0 0 1 4-5"></path>
    </svg> 
    <span class="mt-quote-free-text">
        "#CITA"
    </span>
    <cite class="mt-quote-free-author">#AUTOR</cite>
</blockquote>
```

---

## 2. Instrucciones de Personalización
Para que la cita se muestre correctamente, realiza los siguientes cambios:

- **Contenido:** Reemplaza el valor `#CITA` por la frase o texto que deseas resaltar.
- **Autoría:** Reemplaza el valor `#AUTOR` por el nombre de la persona que dijo la frase.
