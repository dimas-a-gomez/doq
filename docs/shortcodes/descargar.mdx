El shortcode de **Descargar** permite insertar un botón estilizado con el icono oficial de la plantilla para dirigir a los usuarios a archivos externos o recursos descargables.

---

## 1. Código del Shortcode

Para utilizar este botón, copia el siguiente bloque HTML y pégalo en la pestaña **"Vista de HTML"** de tu entrada en Blogger:

```html
<div class="mt-download-container">
    <a href="#URL" class="btn-mountainb" target="_blank">
        <svg class="i i-download" viewBox="0 0 24 24">
            <path d="m7 10 5 5 5-5m-5 5V3m10 12v4a2 2 0 0 1-2 2H4a2 2 0 0 1-2-2v-4"></path>
        </svg> 
        Descargar ahora
    </a>
</div>
```

Reemplaza el valor **#URL** por el enlace del archivo.
