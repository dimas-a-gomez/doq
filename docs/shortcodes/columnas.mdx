# Columnas

El componente `Columnas` te ayuda a acomodar contenido en forma de rejilla o columnas. Generalmente útil para mostrar dos elementos paralelos.

<Columnas>
  <Col>
    <Boton href="#">Elemento 1</Boton>
    Este es el contenido de la primera columna. 
  </Col>
  <Col>
    <Boton href="#" variant="secondary">Elemento 2</Boton>
    Este es el contenido de la segunda columna.
  </Col>
</Columnas>
