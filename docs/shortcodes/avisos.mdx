# Avisos

Los avisos te permiten destacar información importante dentro de tu documentación.
Admiten cuatro variantes de colores.

<Aviso type="info" title="Información">
Este es un mensaje de información. Útil para resaltar notas importantes o aclaraciones.
</Aviso>

<Aviso type="warning" title="Advertencia">
Este es un mensaje de advertencia. Ideal para denotar precaución o posibles inconvenientes.
</Aviso>

<Aviso type="success" title="Éxito">
Este es un mensaje de éxito. Puedes usarlo para confirmar que algo funciona correctamente.
</Aviso>

<Aviso type="error" title="Error">
Este es un mensaje de error. Resalta algo que está obsoleto, roto, o que no debería hacerse.
</Aviso>
