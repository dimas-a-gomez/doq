El shortcode de **Nota** permite insertar un cuadro de texto destacado con un icono de información para captar la atención del lector sobre puntos clave.

## 1. Código del Shortcode

Copia el siguiente bloque HTML y pégalo en la pestaña **"Vista de HTML"** de tu entrada en Blogger:

```html
<div class="mt-note">
    <i class='mt-info'></i> 
    <div class="mt-note-content">
        <b>Nota importante:</b> #NOTA
    </div>
</div>
```

---

## 2. Instrucciones de Personalización
Para adaptar la nota a tu contenido, realiza el siguiente cambio:

- **Contenido de la nota:** Reemplaza el valor `#NOTA`  por el texto informativo o la advertencia que deseas mostrar.
- **Encabezado:** Si lo deseas, puedes cambiar el texto dentro de las etiquetas `<b>...</b>`  (por ejemplo, de "Nota importante:" a **"Consejo:"** o **"Atención:"**).
