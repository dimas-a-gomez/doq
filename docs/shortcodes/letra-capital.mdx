El shortcode de **Letra Capital** aplica un estilo especial a la primera letra de un párrafo, aumentando su tamaño y dándole un diseño distintivo.

## 1. Código del Shortcode

Para utilizar este efecto, copia el siguiente bloque HTML y úsalo al inicio de tu contenido:

```html
<p class="mt-dropcap">
    #PARRAFO-INICIAL
</p>
```

---

## 2. Instrucciones de Personalización
Este componente funciona de forma automática con el texto que introduzcas:

- **Párrafo Inicial:** Reemplaza el valor `#PARRAFO-INICIAL`  por el primer párrafo de tu artículo.
- **Funcionamiento:** No necesitas aplicar estilos manuales a la primera letra; la clase `mt-dropcap`  detectará automáticamente el primer carácter y lo convertirá en letra capital.
