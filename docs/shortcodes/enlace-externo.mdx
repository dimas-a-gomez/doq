El shortcode de **Enlace Externo** permite insertar vínculos dentro de tus textos de forma elegante, incluyendo un indicador visual de salida.

## 1. Código del Shortcode

Copia el siguiente fragmento HTML y úsalo dentro de tus párrafos en la **"Vista de HTML"** de Blogger:

```html
Aquí puedes ver más información en este <a href="#URL" class="mt-link-inline" target="_blank">enlace externo <svg class="i i-arrow-up-right" viewBox="0 0 24 24">
    <path d="M7 17 17 7M7 7h10v10"></path>
</svg></a>.
```

---

## 2. Instrucciones de Personalización
Este elemento es altamente flexible:

- **Dirección web:** Reemplaza el valor `#URL` por la dirección del sitio externo (ejemplo: https://google.com).
- **Texto del enlace:** Puedes cambiar la frase `"enlace externo"`  por cualquier texto descriptivo, como **"ver fuente"** o **"leer más"**.

Contexto: El texto que rodea al enlace (fuera de las etiquetas <a>) también puede ser modificado libremente para adaptarse a tu redacción.
