El shortcode de **YouTube Optimizado** utiliza una miniatura estática y solo activa el reproductor de Google al recibir un clic, evitando que el blog se vuelva lento por scripts externos pesados.

## 1. Código del Shortcode

Copia el siguiente bloque HTML y pégalo en la pestaña **"Vista de HTML"** de tu editor en Blogger:

```html
<div class="mt-video-lazy">
    <div class="mt-video-cover" onclick="this.innerHTML = '<iframe src=\'[https://www.youtube.com/embed/#CODIGO_EMBED_YOUTUBE](https://www.youtube.com/embed/#CODIGO_EMBED_YOUTUBE)\' frameborder=\'0\' allowfullscreen=\'true\' style=\'position:absolute;top:0;left:0;width:100%;height:100%;border-radius:12px;\'></iframe>'">
    
    <img src="#URL_MINIATURA.jpg" alt="Miniatura del video">
    
    <div class="mt-video-play-btn">
        <svg class="i i-play" viewBox="0 0 24 24">
            <path d="m7 3 14 9-14 9z"></path>
        </svg>
    </div>
    </div>
</div>
```

---

## 2. Instrucciones de Personalización
Para que el reproductor funcione correctamente, debes configurar estos dos parámetros:

- **#CODIGO_EMBED_YOUTUBE:** Debes obtener el identificador que aparece en el enlace de inserción de YouTube.
- **Ejemplo:** Si el enlace es `https://www.youtube.com/embed/LXb3EKWsInQ?si=AVep2Z516kIUbkCd` , el código que debes copiar es `LXb3EKWsInQ?si=AVep2Z516kIUbkCd`  (todo lo que va después de embed/).
- **#URL_MINIATURA.jpg:** El enlace directo a la imagen que servirá de portada. Puedes usar la miniatura oficial de YouTube o una personalizada de tu elección.
