# Explorador Visual (Grid/Galería)

Un explorador visual limpia el contenido y lo organiza en una cuadrícula (grid) espaciada. Ayuda a que el usuario previsualice de forma rápida los distintos apartados (como iconos, componentes o guías completas). 

Efectivamente, esto se logra combinando de manera estructurada los _Enlaces de Página_ dentro de _Columnas_. A continuación, te mostramos un ejemplo de cómo se vería una galería.

## Galería de Enlaces de Documentación

Esta cuadrícula es perfecta si quieres hacer un "hub" central al principio de una sección para que los usuarios salten rápidamente a sus temas de interés:

<Columnas>
  <Col>
    <EnlacePagina 
      title="Opciones de Instalación" 
      description="Aprende a configurar paso a paso este proyecto base." 
      href="/docs/installation" 
    />
  </Col>
  <Col>
    <EnlacePagina 
      title="Registro de Cambios" 
      description="Entérate de las últimas versiones, fixes y nuevas funcionalidades." 
      href="/docs/changelog" 
    />
  </Col>
  <Col>
    <EnlacePagina 
      title="Configurando Shortcodes" 
      description="Aprende a crear tus propios shortcodes interactivos en React." 
      href="/docs/shortcodes/codigo" 
    />
  </Col>
  <Col>
    <EnlacePagina 
      title="Componente Badge" 
      description="Resalta de forma elegante los estados, etiquetas o tags de versión." 
      href="/docs/otro/other" 
    />
  </Col>
</Columnas>

## ¿Por qué utilizar esta vista?

1. **Jerarquización:** Permite estructurar módulos en lugar de una lista aburrida vertical.
2. **Claridad:** El usuario puede escanear más de 4 opciones rápidamente gracias al espacio en blanco.
3. **Escalabilidad:** Ideal para índices extensos. En móvil se adapta a 1 sola columna y en pantallas grandes en 2 o más.
