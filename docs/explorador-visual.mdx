# Explorador Visual (Grid/Galería)

Un explorador visual es un patrón de diseño que organiza los elementos en una cuadrícula espaciada. Su función es permitirle al usuario previsualizar de forma rápida los distintos apartados (como rutas, componentes o guías) antes de tomar una decisión de a dónde ir.

En DOQMEN, este patrón se logra anidando los enlaces interactivos (`<EnlacePagina />`) dentro del shortcode `<Columnas />`, lo que genera una estructura en galería completamente adaptable.

## Cuándo Utilizarlo

Se recomienda recurrir a este patrón cuando:
- **Necesitas un "Hub" o Índice Central:** Si tienes una sección general que agrupa varios subtemas, las cuadrículas son perfectas para introducirlos todos.
- **Quieres evitar saturación textual:** Reemplaza las enormes e infinitas listas con viñetas por bloques interactivos escaneables.
- **Mejorar la experiencia móvil:** Proporcionas "áreas de toque" grandes, descriptivas y elegantes que facilitan la interacción en dispositivos pequeños.

## Ejemplo de Visualización

Así es como se ve un explorador visual en plena acción dentro de una página:

<Columnas>
  <Col>
    <EnlacePagina 
      title="Opciones de Instalación" 
      description="Aprende a configurar paso a paso este proyecto base de DOQMEN." 
      href="/docs/installation" 
    />
  </Col>
  <Col>
    <EnlacePagina 
      title="Registro de Cambios" 
      description="Entérate de las últimas versiones, arreglos y funcionalidades." 
      href="/docs/changelog" 
    />
  </Col>
</Columnas>

## Código MDX

Para crear tu propia cuadrícula en cualquier documento, copia y adapta la siguiente estructura. Conforme vayas metiendo nuevas etiquetas `<Col>`, el sistema de columnas se encargará de adaptar su disposición adecuadamente.

```mdx
<Columnas>
  <Col>
    <EnlacePagina 
      title="Opciones de Instalación" 
      description="Aprende a configurar paso a paso este proyecto base de DOQMEN." 
      href="/docs/installation" 
    />
  </Col>
  <Col>
    <EnlacePagina 
      title="Registro de Cambios" 
      description="Entérate de las últimas versiones, arreglos y funcionalidades." 
      href="/docs/changelog" 
    />
  </Col>
</Columnas>
```
