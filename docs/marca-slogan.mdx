La sección de **Marca y Slogan** permite mostrar el nombre de tu proyecto, una breve descripción y un enlace de contacto directo en la parte inferior del sitio.

---

## 1. Activación del Widget

Por defecto, este componente se encuentra desactivado. Para habilitarlo:

* Accede al panel de **Diseño** en Blogger.
* Busca el widget de tipo HTML/JavaScript titulado **"Marca y Slogan"**.
* Cambia el interruptor a **Activado**.

---

## 2. Configuración del Contenido

Debes pegar el siguiente código en el campo **"Contenido"** del widget y reemplazar los valores marcados con `#`:

### Código Base:

```html
<h2 class='brand-name'>#nombre</h2>
<p class='brand-slogan'>#slogan</p>
<a class='brand-email' href='mailto:tu@mail.com'>#mail@</a>
