# Guía de Uso de DOQMEN

DOQMEN es una plantilla de documentación de código abierto construida con Next.js, Tailwind CSS y MDX. Está diseñada para ser rápida, accesible y muy fácil de personalizar.

En esta guía aprenderás cómo descargar el repositorio, instalar las dependencias, modificar la información de tu sitio y crear tus propios documentos.

---

## 1. Instalación y ejecución local

Si has descargado o clonado el repositorio de DOQMEN, sigue estos pasos para correr el servidor de desarrollo en tu computadora:

1. **Instala las dependencias:** Abre tu terminal en la carpeta del proyecto y ejecuta:
   ```bash
   npm install
   ```

2. **Inicia el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

3. **Abre tu navegador:** Ve a `http://localhost:3000` para ver tu sitio en vivo.

---

## 2. Personalizar el nombre del sitio

Para cambiar el nombre "DOQMEN" por el nombre de tu proyecto o marca, debes editar el archivo de configuración principal.

1. Abre el archivo `config/site.ts`.
2. Modifica las propiedades `name` y `description`:

```typescript
export const siteConfig = {
  name: "Mi Nueva Documentación",
  description: "Descripción de mi increíble proyecto.",
  links: {
    github: "https://github.com/tu-usuario/tu-repo",
  },
};
```

Este cambio se reflejará automáticamente en el encabezado, el pie de página y los metadatos (SEO) de todo el sitio.

## 3. Personalizar Colores (Color Principal)

DOQMEN utiliza una estética minimalista monocromática (blanco y negro), pero puedes agregar el color principal de tu marca fácilmente manteniendo el soporte interactivo de modo claro y oscuro.

El color de tu marca se maneja mediante variables CSS. Para cambiar el color principal (denominado "accent" en la plantilla):

1. Abre el archivo `app/globals.css`.
2. Busca la sección `@layer base`.
3. Verás la configuración para el modo normal (`:root`) y el modo oscuro (`.dark`).

Por defecto, DOQMEN invierte el blanco y el negro:
```css
@layer base {
  :root {
    --background: #ffffff;
    --foreground: #0a0a0a;
    --color-accent: #000000; /* Color primario en modo claro */
    --color-accent-hover: #333333; /* Color al pasar el cursor */
    --color-accent-fg: #ffffff; /* Color del texto dentro de elementos con color primario */
  }

  .dark {
    --background: #0a0a0a;
    --foreground: #ededed;
    --color-accent: #ffffff; /* Color primario en modo oscuro */
    --color-accent-hover: #cccccc;
    --color-accent-fg: #000000;
  }
}
```

Para implementar tu propio color de marca (por ejemplo un azul vibrante como `#0066FF`), modifícalo así:

```css
@layer base {
  :root {
    --background: #ffffff;
    --foreground: #0a0a0a;
    --color-accent: #0066FF; 
    --color-accent-hover: #0052CC;
    --color-accent-fg: #ffffff;
  }

  .dark {
    --background: #0a0a0a;
    --foreground: #ededed;
    --color-accent: #3385FF; /* Puedes usar un tono ligeramente más claro para que resalte en fondos oscuros */
    --color-accent-hover: #66A3FF;
    --color-accent-fg: #ffffff;
  }
}
```

Al guardar este archivo, todos los botones, enlaces en la documentación y elementos interactivos adoptarán automáticamente el color de tu marca en toda la web.

## 4. Cambiar el Logo / Icono

El icono que aparece al lado del nombre del sitio en la barra de navegación es un componente de React que renderiza un SVG.

1. Abre el archivo `components/Logo.tsx`.
2. Reemplaza el código `<svg>...</svg>` por el SVG de tu propio logo.
3. Asegúrate de mantener la propiedad `className={className}` en tu etiqueta `<svg>` para que los estilos de tamaño y color se apliquen correctamente.

Ejemplo:
```tsx
export function Logo({ className }: { className?: string }) {
  return (
    <svg className={className} viewBox="0 0 24 24" fill="currentColor">
      {/* El path de tu logo aquí */}
    </svg>
  );
}
```

## 5. Modificar las Características (Features)

En la página principal (`/`) hay una sección de "Features" o características. Para modificar los textos o los iconos de estas tarjetas:

1. Abre el archivo `app/page.tsx`.
2. Busca la sección `<section>` que contiene el título "Features".
3. Dentro verás varios bloques `<div>` que representan cada tarjeta. Puedes cambiar el título `<h3>`, el párrafo `<p>` y el código `<svg>` que representa el icono de cada una.

---

## 6. Crear y subir archivos MDX

DOQMEN utiliza **MDX**, lo que significa que puedes escribir en Markdown normal y al mismo tiempo usar componentes de React (como alertas o botones) dentro de tus documentos.

Todos los archivos de documentación viven en la carpeta `docs/`.

### Crear una nueva página

1. Crea un nuevo archivo en la carpeta `docs/`, por ejemplo `docs/mi-pagina.mdx`.
2. Añade el **Frontmatter** al principio del archivo. Esto define el título y la descripción de la página:

```mdx
---
title: "Mi Primera Página"
description: "Esta es una página de prueba."
---

# Hola Mundo

Aquí va el contenido de tu documentación.
```

### Organizar la navegación

Para que tu nueva página aparezca en el menú lateral con el nombre y orden correctos, debes editar el archivo `docs/_meta.json`.

```json
{
  "index": {
    "title": "Inicio",
    "icon": "Home"
  },
  "mi-pagina": {
    "title": "Mi Primera Página",
    "icon": "FileText"
  }
}
```
*Nota: La clave en el JSON (`mi-pagina`) debe coincidir exactamente con el nombre de tu archivo sin la extensión `.mdx`.*

¡Y eso es todo! Con estos pasos ya puedes adaptar DOQMEN a tus necesidades y crear documentación increíble.
