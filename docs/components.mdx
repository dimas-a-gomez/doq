# Components

Hudocs comes with a few built-in components that you can use directly in your MDX files.

## Alerts

Alerts are useful for highlighting important information, warnings, or success messages.

### Info Alert

<Alert type="info" title="Did you know?">
  You can use MDX to embed React components directly into your Markdown files.
</Alert>

```mdx
<Alert type="info" title="Did you know?">
  You can use MDX to embed React components directly into your Markdown files.
</Alert>
```

### Warning Alert

<Alert type="warning" title="Warning">
  This feature is currently in beta and may change in the future.
</Alert>

```mdx
<Alert type="warning" title="Warning">
  This feature is currently in beta and may change in the future.
</Alert>
```

### Success Alert

<Alert type="success" title="Success">
  Your changes have been saved successfully.
</Alert>

```mdx
<Alert type="success" title="Success">
  Your changes have been saved successfully.
</Alert>
```

### Error Alert

<Alert type="error" title="Error">
  An unexpected error occurred while processing your request.
</Alert>

```mdx
<Alert type="error" title="Error">
  An unexpected error occurred while processing your request.
</Alert>
```
