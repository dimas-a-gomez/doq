The **Hero Welcome** is the visual block that appears at the top of your blog. By default, this widget is disabled so you can personalize your initial impact message.

## 1. Widget Activation

To make the message visible, follow these steps in the Blogger dashboard:

* Go to the **Layout** section.
* Look for the gadget named **"Hero Welcome"**.
* Switch the status to **ON** so the content renders on the web.

---

## 2. Content Configuration

This component uses an **HTML/JavaScript** gadget. You must paste the base code into the **"Content"** field and replace the text placeholders.

### Base Code:
Copy and paste the following code block:

```html
<div class="hero-welcome">
    <h1 class="hero-title">#title</h1>
    <p class="hero-desc">#description</p>
</div>
