El **Hero Welcome** es el bloque visual que aparece en la parte superior de tu blog. Por defecto, este widget se encuentra desactivado para que puedas personalizar el mensaje de impacto inicial.

## 1. Activación del Widget

Para que el mensaje sea visible, sigue estos pasos en el panel de Blogger:

* Ve a la sección **Diseño**.
* Busca el gadget con el nombre **"Hero Welcome"**.
* Cambia el estado a **Activado** para que el contenido se renderice en la web.

---

## 2. Configuración del Contenido

Este componente utiliza un widget de tipo **HTML/JavaScript**. Debes pegar el código base en el campo **"Contenido"** y reemplazar las etiquetas de texto.

### Código Base:
Copia y pega el siguiente bloque de código:

```html
<div class="hero-welcome">
    <h1 class="hero-title">#titulo</h1>
    <p class="hero-desc">#descripcion</p>
</div>
