# Registro de Cambios

Todas las actualizaciones notables de DOQMEN se documentarán en esta página.

## Versión 2.06 <Badge variant="accent">Última</Badge>

**5 de Junio de 2026**

### Mejorado
- Se implementaron actualizaciones en el script de SEO para generar automáticamente el Sitemap y el índice de búsqueda interno.
- Se añadió personalización de selección de texto (`::selection`) más amigable y accesible de acuerdo al tema claro u oscuro establecido.
- Se configuró la etiqueta meta requerida por _Google Search Console_ para la verificación de propiedad del dominio.

## Versión 2.05 <Badge>Estable</Badge>

**5 de Junio de 2026**

### Añadido
- Nuevo soporte para mostrar **Tooltips (descripción emergente)** en los enlaces de la barra lateral (Sidebar) cuando el usuario pasa el cursor.
- Implementación de la variable `description` en `config/docs.ts` para nutrir la información del Tooltip de cada enlace.
- Añadida la funcionalidad de **"Editar esta página"** al pie de cada artículo conectándolo a un enlace directo con GitHub a través de los metadatos.
- Nuevo enlace en la página de Metadatos (Frontmatter) para documentar cómo incluir el botón de GitHub.

### Mejorado
- El Tooltip de la barra lateral adopta un contraste directo y usa colores de superficie (oscuro o claro dependiendo del tema).

## Versión 1.1.0 <Badge>Estable</Badge>

**4 de Junio de 2026**

### Añadido
- Añadido un nuevo sistema de búsqueda con atajo de teclado (`⌘` + `K`).
- Nuevo componente interactivo `<Badge />` para destacar etiquetas en los títulos y enlaces del sidebar.
- Añadido el resaltado de sintaxis personalizado adaptable a fondos claros y oscuros.
- Nueva página de **Registro de cambios (Changelog)** para hacer seguimiento de las versiones.

### Mejorado
- Refactorización de la barra lateral (Sidebar) para mostrar etiquetas (badges) junto a los títulos.
- Mejorada la legibilidad de tablas, unificando bordes y márgenes.

## Versión 1.0.0 <Badge>Estable</Badge>

**1 de Junio de 2026**

### Añadido
- Lanzamiento inicial de DOQMEN.
- Soporte base para archivos MDX.
- Shortcodes: Avisos, Botones, Tablas, Columnas, y Enlaces de Página.
- Funcionalidad de modo oscuro y modo claro integrado.
