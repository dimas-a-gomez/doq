# Instalación

Aquí encontrarás la guía para instalar y arrancar la aplicación de documentación.

---

## Requisitos Previos

- Node.js 18.17 o versiones superiores.
- Gestor de paquetes: `npm`, `yarn` o `pnpm`

### Instalar dependencias

Una vez clonado el proyecto, puedes ejecutar el siguiente comando para instalar las librerías necesarias:

```bash
npm install
```

### Iniciar servidor de desarrollo

Para iniciar el servidor local y ver los cambios en vivo, ejecuta:

```bash
npm run dev
```

Abre tu navegador en `http://localhost:3000` y disfruta de la nueva y limpia interfaz.
