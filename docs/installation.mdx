There are two ways to install the **MountainB** template. While the restore option is fast, for PC users we recommend the **Total Copy** method to avoid conflicts with previous theme configurations.

---

## Recommended Method (PC)

This method ensures a clean installation by replacing all existing code.

### 1. Prepare the XML Code
* Open the template's `.xml` file on your PC.
* You can use **Notepad** or **Visual Studio Code**.
* Select all the text (`Ctrl + A` or right-click and "Select All") and copy it (`Ctrl + C`).

### 2. Clear the Blogger Editor
* In your Blogger dashboard, go to **Theme** and click the arrow next to "Customize."
* Select **Edit HTML**.
* Click inside the code editor, select everything, and **delete it completely**.

### 3. Paste and Save
* Paste the **MountainB** code you copied (`Ctrl + V`).
* Click the **Save** icon (the floppy disk) in the top right corner.

---

## Alternative Method (Mobile)

If you are performing the process from a smartphone, the copy-paste method can be difficult to manage. In that case, use the **Restore** option:

1. In the **Theme** section, click the arrow next to "Customize."
2. Select **Restore**.
3. Upload the `.xml` file directly from your local storage.

---

> **Pro Tip:** If you see strange widgets in your layout after installing, go to the **Layout** section in Blogger and remove any elements belonging to your old template so the **MountainB** interface looks flawless.
