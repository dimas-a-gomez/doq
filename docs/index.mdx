# Introduction

Welcome to **Hudocs**. This is a modern, fast, and beautiful documentation template built with Next.js, Tailwind CSS, and MDX.

<Alert type="info" title="Note">
  This documentation site is a work in progress. More features will be added
  soon.
</Alert>

## Features

- **MDX Support**: Write your content in Markdown and embed React components seamlessly.
- **Syntax Highlighting**: Beautiful code blocks powered by `rehype-pretty-code` and Shiki.
- **Fast & Accessible**: Built on Next.js App Router for maximum performance and SEO.
- **Glassmorphism**: A modern aesthetic with subtle borders and blurred backgrounds.

## Getting Started

To get started, simply edit the files in the `/docs` directory. The routing is handled automatically based on the file names.

```bash
npm run dev
```

<Alert type="success" title="Success">
  You are now ready to build your documentation!
</Alert>
