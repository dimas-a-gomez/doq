# Introducción

¡Bienvenido a DOQMEN! Esta es la reconstrucción de la documentación, hecha desde cero y cumpliendo con todas las especificaciones solicitadas.

## Características

- Sin bordes y sin sombras globales (CSS).
- Tipografía **Vend Sans** por defecto.
- Tipografía **Space Mono** en los menús laterales y código.
- Diseño minimalista, estilo documentación pura.
- El ícono `#` ahora se muestra correctamente al posaer el puntero sobre cualquier título o subtítulo.
- Header color sólido, y color `#141414` en modo oscuro.

### Listos para Empezar

Con esta nueva base podemos comenzar a crear páginas limpias y fluidas. Vea la [Instalación](/docs/installation) para continuar.
