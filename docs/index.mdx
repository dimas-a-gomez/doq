# Introducción

¡Bienvenido a **DOQMEN**! Un proyecto base para documentación moderno, limpio y elegante, creado con Next.js, Tailwind CSS y MDX (Markdown). Mantenemos un enfoque puramente visual en el contenido para que puedas crear guías, tutoriales y manuales claros que sean un deleite leer, ya sea desde tu teléfono móvil o tus monitores ultra anchos.

## Características Principales

DOQMEN ha sido construido desde cero, manteniendo la simplicidad por bandera:

- 📝 **Markdown + React (MDX):** Escribe contenido ágilmente usando Markdown enriquecido con componentes interactivos.
- 🎨 **Diseño Minimalista:** Sin bordes excesivos, sin sombras globales y con soporte nativo para Modo Oscuro y Claro.
- ⚡️ **Shortcodes Listos para Usar:** Incluye componentes interactivos en React como `<Aviso />`, `<Boton />`, `<Badge />`, `<Columnas />`, y `<EnlacePagina />`.
- 🔍 **Búsqueda Integrada:** Un sistema rápido de atajos de teclado (`⌘` + `K`) para saltar a cualquier tema o página, adaptado visualmente a todo este minimalismo.
- 📱 **Totalmente Responsivo:** Una experiencia fluida y hermosa que se adapta a cualquier resolución.
