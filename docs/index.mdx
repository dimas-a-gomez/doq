## Créditos

- **Zkreations**: Por la base estructural de **Hamlet**, que sirvió como cimiento para este proyecto. También su paquete de iconos **Meteor**.
- **Google Blogger**: Por proporcionar la plataforma que nos permite seguir experimentando con el diseño web.
- **Comunidad de Desarrolladores**: A todos los que comparten sus conocimientos sobre la lógica de los widgets de Blogger y optimización XML.
- **Google Fonts**: Proporcionó las fuentes **Figtree** y **Glock**, tipografías muy bonitas.
- **Blogger Code PE**: Un material superimportante para blogger.
- **Gemini**: Una IA que me ayudó con el código de la plantilla, superrecomendable cuando haya problemas.
