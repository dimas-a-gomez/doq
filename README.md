# DOQMEN

Un proyecto base para documentación moderno y elegante, creado con Next.js, Tailwind CSS y MDX (Markdown). Diseñado para ser rápido de configurar y fácil de personalizar.

> **Nota:** La documentación completa sobre cómo usar, personalizar y extender DOQMEN está construida usando DOQMEN mismo. Visita el sitio web o arráncalo localmente para leer todas las guías.

## Características principales

- 📝 **Markdown + React (MDX):** Escribe contenido ágilmente usando Markdown enriquecido con componentes interactivos.
- 🎨 **Diseño Minimalista:** Construido usando Tailwind CSS con soporte nativo para Modo Oscuro y Claro.
- ⚡️ **Shortcodes Listos para Usar:** Incluye Tablas, Avisos, Botones, Badges (etiquetas), Columnas, y Enlaces de página integrados.
- 🔍 **Sistema de Búsqueda:** Navegación ultra-rápida implementada (Atajo `⌘` + `K`).
- 📱 **Totalmente Responsivo:** Una experiencia de usuario fluida desde móviles hasta monitores anchos.

## Requisitos previos

- **Node.js** (Versión 18 o superior recomendada).
- Gestor de paquetes (`npm`, `yarn`, `pnpm`, o `bun`).

## Configuración local

Para ejecutar DOQMEN directamente desde tu computadora y comenzar a editar la documentación, sigue estos pasos:

1. **Clona el repositorio** e ingresa a la carpeta del proyecto:
   ```bash
   git clone https://github.com/TODO_TU_USUARIO/doqmen.git
   cd doqmen
   ```

2. **Instala las dependencias necesarias:**
   ```bash
   npm install
   ```

3. **Inicia el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Visualiza el sitio:**
   Abre [http://localhost:3000](http://localhost:3000) (o el puerto que se indique en tu terminal) en tu navegador.
